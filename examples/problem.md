# 最大连续子段和

## 题目描述
给定一个长度为 $n$ 的整数序列 $a_1,a_2,\ldots,a_n$，求非空连续子段的最大元素和。
子段必须至少包含一个元素。输出唯一的最大和。

## 输入格式
第一行一个整数 $n$。
第二行 $n$ 个整数 $a_1,a_2,\ldots,a_n$，以空格分隔。

## 输出格式
输出一个整数，表示非空连续子段的最大元素和。

## 输入样例
```input
5
-2 3 -1 4 -5
```

## 输出样例
```output
6
```

## 数据范围
$1 \le n \le 200000$，$-10^9 \le a_i \le 10^9$。
所有输入都是整数，无其他约束，无子任务分组要求。

## 资源限制
时间限制：1000 ms。空间限制：256 MiB。
